## מבנה הדו"ח

הדו"ח עצמו נמצא בתאי ה-markdown בתוך המחברת, מסודר לפי סעיפי המטלה:

- **חלק 1** — דגימה, משפט נייקוויסט, aliasing וקוונטיזציה.
- **חלק 2** — חישוב SNR בשתי דרכים, oversampling, והחלקה במלבני ומשולשי.
- **חלק 3** — ניתוח רכבות ספייקים: קצב ירי, Fano factor, ISI, raster, PSTH, אוטוקורלציה וקרוס-קורלציה.

## הערות טכניות

- תדר הדגימה של `Neural_data.csv` הוא 50 Hz, ולכן 30 שניות הקלטה = 1500 דגימות.
- דגימה מחדש בסעיף 1.2 נעשית ידנית באמצעות `signal[::dec]`, ללא מסנן אנטי-aliasing — בכוונה, כדי לראות את התופעה.
- חישוב ה-SNR נעשה בשתי השיטות שנלמדו בהרצאה (Lec2_2): יחס הספקים (Definition #1), ו-mean/std (Definition #2).
- כל ניתוחי חלק 2 (החל מסעיף 2.2) מתבצעים על אזור הגירוי בלבד (שניות 12–30).
- ב-cross-correlation בחלק 3 אין נרמול, בהתאם להוראת המטלה.
